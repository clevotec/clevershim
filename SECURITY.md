# Security Policy

## Supported versions

Security fixes are applied to the latest released version of CleverShim on the default branch. Older tags are not maintained.

## Reporting a vulnerability

Please report security issues privately through GitHub's private vulnerability reporting for this repository:

https://github.com/clevotec/clevershim/security/advisories/new

Do not open a public issue for security reports.

Include as much of the following as you can:

- Affected version, commit, or release tag
- Impact and attack scenario
- Steps to reproduce
- Any known workarounds

We will acknowledge reports as soon as practical, investigate privately, and coordinate disclosure through a GitHub security advisory when a fix is ready.
